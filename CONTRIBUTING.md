## 🤝 Contribuindo

Toda contribuição é bem-vinda.

1. Faça um Fork
2. Crie uma Branch

```
feature/minha-feature
```

3. Faça commits descritivos

```
feat(bank): adiciona sistema de empréstimos
fix(chat): corrige mensagem duplicada
refactor(company): melhora gerenciamento de empresas
```

4. Abra um Pull Request.

---

## 📋 Padrão de Código

- Código modular
- Funções documentadas
- Nomes em inglês
- Comentários apenas quando necessário
- Evitar código duplicado

---

## 🚀 Compilando

Clone o repositório

```bash
git clone https://github.com/BPC-Players-Community/gamemode.git
```

Abra o projeto no VSCode e compile normalmente.
